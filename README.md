AI Career Navigator

О проекте

AI Career Navigator — интеллектуальный карьерный навигатор,
который помогает пользователю определить подходящее направление
развития, выявить пробелы в навыках и построить персональный
карьерный маршрут.

Возможности

- выбор целевой профессии;
- указание текущих навыков и их уровня;
- AI-анализ профиля;
- определение недостающих навыков;
- персональный roadmap;
- подбор вакансий;
- оценка соответствия требованиям вакансий;
- сохранение истории анализов.

Как работает

1. Пользователь выбирает профессию.
2. Указывает свои навыки и опыт.
3. Backend сохраняет данные в PostgreSQL.
4. FastAPI отправляет данные на AI-анализ.
5. AI определяет пробелы и формирует roadmap.
6. Система подбирает подходящие вакансии.
7. Пользователь получает карьерный маршрут.

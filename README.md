# AI Career Navigator

# О проекте

AI Career Navigator — интеллектуальный карьерный навигатор,
который помогает пользователю определить подходящее направление
развития, выявить пробелы в навыках и построить персональный
карьерный маршрут.

# Возможности

- выбор целевой профессии;
- указание текущих навыков и их уровня;
- AI-анализ профиля;
- определение недостающих навыков;
- персональный roadmap;
- подбор вакансий;
- оценка соответствия требованиям вакансий;
- сохранение истории анализов.

# Как работает

1. Пользователь выбирает профессию.
2. Указывает свои навыки и опыт.
3. Backend сохраняет данные в PostgreSQL.
4. FastAPI отправляет данные на AI-анализ.
5. AI определяет пробелы в навыках и формирует roadmap.
6. Система подбирает подходящие вакансии.
7. Пользователь получает персональный карьерный маршрут.

# Архитектура

Пользователь
     ↓
React + TypeScript
     ↓
FastAPI
     ├── OpenAI API
     ├── HH.ru API
     ↓
PostgreSQL

# HH.ru

Интеграция с HH.ru API подготовлена.

На момент разработки проекта заявка на регистрацию приложения
находится на рассмотрении.

В случае одобрения приложения система сможет использовать
доступ к API HH.ru для получения реальных вакансий.

# Команда
Разработчик — разработка программной системы, frontend и backend.
Системный аналитик — сбор требований, проектирование архитектуры и процессов.
Бизнес-аналитик — анализ проблемы, целевой аудитории и ценности продукта.
DevOps / Инфраструктура — настройка окружения, deployment и инфраструктуры.
Дальнейшее развитие
анализ GitHub-профиля пользователя;
анализ резюме;
AI-чат после анализа;
более точное сопоставление навыков пользователя с требованиями вакансий;
расширение списка профессий;
персональные рекомендации по проектам и курсам.

# Использованные технологии и инструменты

## Разработка

- **Python** — разработка backend-части;
- **FastAPI** — создание REST API;
- **React + TypeScript** — разработка frontend;
- **Vite** — сборка и запуск frontend;
- **PostgreSQL** — хранение данных пользователей, навыков и карьерных маршрутов.

## Искусственный интеллект

- **OpenAI API** — анализ профиля пользователя, определение пробелов в навыках и формирование карьерного маршрута.

## Внешние сервисы

- **HH.ru API** — получение и подбор вакансий.

## Развёртывание

- **Railway** — размещение frontend и backend приложения.

## Инструменты разработки

- **Git** — контроль версий;
- **GitHub** — хранение исходного кода и совместная работа над проектом;
- **Swagger / OpenAPI** — тестирование и документирование API.
- **ChatGPT** — использовался как вспомогательный инструмент при проектировании архитектуры, разработке и отладке проекта, подготовке документации и поиске решений технических задач.
